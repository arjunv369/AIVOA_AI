BATCH 5 CLEAN REPLACEMENT

Backend:
1. Copy backend/*.py and backend/requirements.txt into your backend folder.
2. From backend:
   python -m pip install -r requirements.txt
3. Create the MySQL database:
   CREATE DATABASE complaints CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
4. Set the real DATABASE_URL and GROQ_API_KEY in your root .env.
5. Use:
   GROQ_MODEL=openai/gpt-oss-120b

Frontend:
1. Copy the src files into frontend/src.
2. Copy vite.config.ts and tsconfig.app.json into frontend/.
3. Make sure @tanstack/react-router is installed:
   npm install @tanstack/react-router
4. Build:
   npm run build

Run:
Backend:
   cd backend
   python -m uvicorn main:app --reload

Frontend:
   cd frontend
   npm run dev

API:
   http://127.0.0.1:8000/docs
